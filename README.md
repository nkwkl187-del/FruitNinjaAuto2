# Fruit Ninja Auto

مشروع تجريبي لأندرويد يلتقط الشاشة عبر MediaProjection ويستخدم AccessibilityService لتنفيذ سحب على الأجسام الملونة، مع فلتر أمان يستبعد الأجسام الداكنة/البنفسجية التي تشبه القنابل في لقطات Fruit Ninja المرفقة.

## التشغيل
1. افتح المشروع في Android Studio.
2. اسمح له بتنزيل Gradle/Android SDK عند الطلب.
3. ابنِ APK من Build > Build APK(s).
4. ثبّت APK على الهاتف.
5. افتح التطبيق، ثم فعّل "Fruit Ninja Auto" من إعدادات إمكانية الوصول.
6. اضغط "بدء التقاط الشاشة" ووافق على نافذة النظام.
7. افتح Fruit Ninja.

## ملاحظات مهمة
- هذا نموذج أولي يعتمد على تحليل ألوان بسيط، وليس ضماناً لتجنب كل قنبلة.
- اختبره أولاً في وضع لا يهمك فيه فقدان الجولة.
- اختلاف دقة الشاشة أو إصدار اللعبة قد يتطلب تعديل العتبات في FruitDetector.kt.
